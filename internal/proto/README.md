# Official StatsService schemas

Sources: XTLS/Xray-core v1.260327.0 and v2fly/v2ray-core/v5 v5.54.2, `app/stats/command/command.proto` from checksum-verified Go modules. Wire package, service names, message field numbers and types are preserved. Only Go package options, local file paths, and V2Fly core registration extensions (not used by this client) are changed.

Independent filenames prevent protobuf global registry collisions. Importing the upstream Go packages also pulls in both entire core runtimes and their conflicting common schemas; this program deliberately uses only these generated API messages.

Generated by protoc 33.0, protoc-gen-go v1.36.12 and protoc-gen-go-grpc v1.5.1. Regeneration: `scripts/generate-proto.ps1` with tools present under `.tools`. Generated files are committed; production builds need only Go.

Xray source license: Mozilla Public License 2.0. V2Fly source license: MIT. Copies of upstream license texts are included alongside the schemas.

sing-box sources: SagerNet/sing-box v1.14.0 `experimental/v2rayapi/stats.proto` and `daemon/started_service.proto`. StatsService is **not** the V2Fly service name: its actual package is `experimental.v2rayapi`. Native schema is a read-only projection of GetVersion, GetStartedAt, SubscribeStatus and SubscribeConnections; unused process metadata and mutating methods are omitted. Field numbers and types remain exactly as upstream. Source license GPL-3.0-or-later with upstream naming restriction; upstream LICENSE is retained in each directory. These generated schemas retain their upstream licenses.

Xray HandlerService 的 `xrayhandler/handler.proto` 是 v26.3.27 只读 wire projection，只生成 ListInbounds/GetInboundUsers/GetInboundUsersCount。嵌套字段保持官方 field numbers，省略完整 core.Config，避免载入完整核心运行时；不生成用户增删 RPC。Account 数据只在内存中用于识别协议/匿名资产哈希，不进入诊断历史。MPL-2.0 许可证已随文件保留。

V1.3 多核心统一诊断：Stats wire schema 重新对照 Xray v26.3.27、V2Fly v5.53.0、sing-box v1.14.3；sing-box 原生投影字段保持兼容。新增 `v2flyobserve/observe.proto` 是 v5.53.0 ObservatoryService 只读投影，保留 GetOutboundStatus 的请求 Tag=1、响应 status=1、状态数组=1，仅获取数量。不引入用户变更或日志重启方法；handler/logger 的注册状态通过可选 ReflectionService 枚举验证。

V1.4：原生投影再次按 sing-box 1.14.3 / API version 4 核实，新增只读 SubscribeServiceStatus 及官方状态枚举；错误正文仍省略。连接初始 reset 包含有界关闭历史，关闭记录不判在线，用户流量只累计稳定连接的实际观测差值。未生成 CloseConnection 或任何配置写入方法，服务端用户管理由独立受控配置代理执行。

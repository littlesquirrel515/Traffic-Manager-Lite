# v2.3 优选订阅生成

## 研究依据

阅读了 [cmliu/edgetunnel](https://github.com/cmliu/edgetunnel) 的 README、`_worker.js` 中优选订阅生成、本地IP库、TXT/CSV API、BEST_SUB 生成器交互与地址去重实现。审计时主分支提交为 `a8ab11125ece9bc27983f609a6359be81b21050c`，下载参考文件 SHA256 为 `1e84d11af0544654bf56a06fa833e77184a57193288a9ffccf62c031a9fb7d65`。参考源码只保存在被忽略的工具目录，产品使用独立 Go 实现，不引入 Worker 运行时、外部订阅转换器或其代理隧道。

该功能生成候选节点；随机地址没有测速，也不能由 VPS 的线路推断用户运营商表现。Cloudflare 随机 IPv4 池依据 2026-10-31 核对的[官方列表](https://www.cloudflare.com/ips-v4)，最多100条；IPv6/域名可通过本地表或外部源导入。

## 使用

节点分组 → 优选订阅生成（也可在分组行选择生成优选节点）：

1. 选择已有 TLS VLESS/VMess/Trojan WS、XHTTP 或 gRPC 节点模板。REALITY、HY UDP、AnyTLS TCP 不能简单套用 CDN 地址，不提供错误的生成组合。
2. 选择新建分组或追加到已有分组，设置前缀、默认端口和本批数量（1–500）。
3. 每行粘贴 `地址[:端口]#备注`，或导入 UTF-8 TXT/CSV。IPv6 带端口用 `[IPv6]:443`。CSV 支持 IP/IP地址、端口、TLS、备注/国家/城市/数据中心，非 TLS 行会跳过；支持 CloudflareST 的 IP 列及默认端口。有效条目按来源顺序截取、去重，并显示跳过/截取数量。
4. 可读取公开 HTTPS TXT/CSV/Base64 地址 API，或选择 edgetunnel BEST_SUB 生成器。后者的服务端须启用 BEST_SUB，TML 仅发送公开占位 host/uuid；不发送真实客户端身份、订阅 Token 或 API Secret。读取失败不会生成伪装错误节点。外部 VLESS/Trojan/SS/VMess 链接只取地址、端口和备注，认证、Host/SNI/Path 一律不用；模板与用户身份仍以 TML 数据为准。
5. 预览名称、地址、端口、继承参数与新增/复用数量，确认后生成。已有分组只追加，不替换原成员或改变启停状态。
6. 到订阅用户选择节点或分组并确认；客户端更新原统一 URL。新增候选不是用户授权，不创建公共无认证下载地址。一个用户在同来源多个节点仍按原服务编排复用一个 Client/计费来源。

## 一致性和安全

008 为追加迁移，不修改 001–007。入口、稳定绑定、节点、分组成员和幂等记录处于同一事务。模板/分组状态变化会使旧预览失效；同一模板相同有效连接参数复用已生成节点。已停用或人工改动的既有生成节点不会被覆盖/启用；已完成批次重放不恢复后续删除对象。未知网络状态仍为 Unknown，不因保存成功宣称连通或低延迟。

复用已有连接创建服务，只改变 Address/Port，Host/SNI 与其他客户端参数从模板继承；协议与底层 Inbound 身份不变，保留模板有效覆盖及稳定归属。不得保存外部账号认证到节点。诊断、采集、配额、计费、30天归档和统一订阅 Token 机制不变。

所有接口要求管理员鉴权。外部源仅 HTTPS 443/8443，无 URL 账号认证；每次实际拨号检查并固定全组 DNS 地址，拒绝私网/环回/链路本地/元数据/共享地址/特殊网段，不使用环境代理、不跟随重定向，不发送客户端认证或 Cookie；8秒超时、响应上限512KiB。URL 与外部响应正文不进入持久日志。生成请求只保存请求哈希与无认证结果。

## 验证

测试覆盖 TXT/CSV/IPv6/Base64/外部认证丢弃、数量和响应限制、受限IP、官方池随机样本、生成幂等与跨批去重、Path/packet-up/fingerprint继承、组成员保留、用户权限不扩张、过期预览拒绝、第二项失败整批回滚和管理员鉴权。浏览器仅使用临时数据库和 fixture API，覆盖预览、生成、异常行统计、三种表单尺寸和原有响应式页面。

生产部署前在隔离生产库副本进行生成与订阅验证；生产只升级应用和做只读预览，不替管理员选择未测速地址或自动创建优选分组。

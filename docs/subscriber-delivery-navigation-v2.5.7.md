# v2.5.7 订阅用户与访问日志职责归位

| 菜单 | 职责 |
| --- | --- |
| 订阅用户 | 用户身份、配额/到期、节点权限；每行订阅链接集中查看/复制、脱敏预览、明确确认后重置 |
| 订阅访问日志 | 客户端请求结果、真实来源 IP 与解析依据；只读观察，不创建、编辑、删除或重置链接 |
| 订阅设置 | 站点订阅域名、全局交付设置 |

统一链接管理集中在用户行的“订阅链接”弹窗；由同一用户的当前权限交付，不增加第二套授权。已有历史独立链接只在其所属用户的弹窗中提供兼容管理（查看、编辑、导出、删除和明确重置），不再在顶层页面提供新建高级订阅入口。后端兼容 API 保留，不删除已有链接。

导航改为 `#subscriptionlogs`；旧 `#catalogsubs` 书签归一到新日志页面。日志页面按用户、结果、格式和文本筛选 API 返回的最新 200 条，明确显示范围；数据库中的旧日志均保留。已删除链接无法关联用户时明确展示，不凭客户端/IP猜身份。用户弹窗可跳转并筛选该用户日志。

普通查看和取消预览/重置不更换 Token；统一订阅仍受 v2.5.6 删除保护；确认为重置后才调用 confirmed=true。弹窗关闭清除明文 URL，不将 Token 放入页面路由、存储或日志。无需迁移，不修改节点、授权、核心或流量账本。

## v2.5.8 快捷脱敏预览

订阅用户每行操作栏提供直接“脱敏预览”，链接弹窗保留同名入口。新增管理员 POST subscribers/{id}/preview，按已保存统一交付配置或默认配置解析当前节点权限；没有统一链接也能预览，不生成 Token、不访问核心、不写业务记录。复用同一脱敏 Renderer，并禁止缓存。

# v2.5.5 Hosts 分组展示

Hosts 通过 preferred_sync_slots → preferred_sync_jobs 的持久关联确定同步归属，包含 inactive 槽位；不通过名称或当前 node_group_members 推断。无需迁移。同步来源组和节点授权分组保持不同职责。

同步组默认折叠，展示正在发布和暂停发布数量、匹配数量；提供搜索名称、备注、地址、Host、SNI，以及服务器、实例、协议、入站、来源和发布状态筛选。手动绑定入口和无绑定共享模板分别展示。搜索与筛选会展开匹配组，支持展开全部和收起同步组。

同步入口在本页面只展示引用与组级同步设置/记录入口，避免逐条改地址触发同步冲突；暂停同步任务并不撤销最后发布。手动入口保留编辑、复制、删除、批量编辑和可见转义备注。Host/SNI 和协议参数继续沿用创建同步任务时的模板，不新增修改同步模板的批量写入功能。

本次不改节点成员、用户授权、计费、认证或核心，不自动创建 Client。测试只使用临时数据库和浏览器夹具，线上验证为只读页面/API及原订阅回归。

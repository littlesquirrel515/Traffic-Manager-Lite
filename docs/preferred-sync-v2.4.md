# v2.4 定时优选同步

节点分组 → 定时优选同步 → 新建同步组。选择可用的 TLS WS/XHTTP/gRPC 模板，每行填写一个公开 HTTPS 来源，选择入口数量与间隔。默认两份 BestCF US、5 个入口、10 分钟、443；8443 可选。首次至少需要同等数量的有效候选。给订阅用户分配该组一次，继续使用原统一订阅 URL。高级订阅如使用独立范围，也需包含相应组或节点。仅给了模板访问权限的用户不会自动获得新组。

同步任务轮询来源，按规范化地址和端口去重、轮流取候选；同一地址尽量留在原入口。实际更新专属 Endpoint 的 Address/Port，Node/Binding ID、Host/SNI、协议配置及用户授权不变。后台不调用 AddUser、不写核心配置或计费数据；前台订阅读库，不在请求时拉外部源。当前候选不足时未填满的入口暂不发布，保留授权；手工停用或修改导致差异时阻止整个批次覆盖。暂停保留最后发布，可立即同步、恢复或编辑来源及间隔。

每源独立缓存，失败后可使用最多 24 小时的缓存补位；所有来源不可用时，继续提供最后一次发布并显示状态。建议保留普通域名备用节点。来源校验复用公网 HTTPS、实际拨号 DNS 校验、禁止重定向及响应大小限制，不接收带查询参数的来源 URL。候选域名同步时检查公共 DNS；客户端实际解析可能不同。来源为管理员明确选择的地址信任边界，建议保持客户端 TLS 验证开启。发布不等于测速或线路验证。

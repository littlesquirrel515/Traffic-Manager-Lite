# v2.2：节点权限 CRUD、可查看链接与自适应订阅

## 产品行为

订阅用户的“分配节点”改为完整编辑：回显当前分配，可以增加、取消单个节点或清空全部。提交前展示新增、删除、保留的数量及名称；预览摘要同时覆盖当前权限和目标，其他管理员修改后必须重新预览。取消只影响后续订阅发布，不删除核心 Client、不踢连接、不清零计数、不冻结仍可能产生流量的计费来源。客户端已缓存配置仍可能继续使用；需要撤销认证是另一项有连接影响的业务，不能把删除订阅节点冒充即时封禁。

新建/追加仍复用既有加密 Desired、只读后添加、回读与幂等任务。删除产生明确撤销记录，对旧订阅、旧动态分组和新统一链接均生效；原生客户端不被改写。同来源仍有其他授权节点时复用认证与计费；全部节点撤销时停止该用户 TML 账号的自动恢复，保留实际账号与账本。旧任务重试不得重新发布已撤销节点；明确重新分配可以复用现有认证或原先的 pending Desired，不生成重复账号。权限变更任务自身可重试，后续编辑替代之前尚未执行的变更。

## 一个用户一个统一入口

订阅用户列表提供“订阅链接”：管理员随时查看、复制，默认不必选择格式或创建多份订阅。统一链接跟随当前节点权限；首次查看时按需建立一份统一订阅资源，之后读取同一链接。高级订阅仍可保留有意限定的节点集合、格式与模板，避免强行合并旧资源扩大权限。

同一 URL 识别 `v2rayN/...` 返回 Base64 URI 列表；`clash-verge/v...`、`mihomo/...` 等返回 Mihomo 完整 YAML（含 proxies、选择组和规则）。浏览器/未知 UA 使用统一订阅的 Base64 默认值。显式 `?format=base64` 或 `?format=mihomo` 优先，作为自定义 UA 的兼容入口；无法从被改写的 UA 百分之百识别客户端。响应设置 `Vary: User-Agent, Accept`、`private, no-store`、实际格式头及原有配额元数据。协议与传输的实际支持过滤保持不变，不因统一 URL 伪造 XHTTP 等能力。

- [v2rayN 官方 User Agent 说明](https://github.com/2dust/v2rayN/wiki/Description-of-some-ui)
- [Clash Verge Rev 官方默认 UA 与网络请求](https://github.com/clash-verge-rev/clash-verge-rev/blob/main/src-tauri/src/utils/network.rs)

## 管理员查看链接与安全

用户明确要求管理员可重复查看 URL，因此改变此前“仅哈希、明文显示一次”的限制：公开鉴权仍只比较 SHA256；可查看的 Token 由独立 `TML_MANAGED_KEY_FILE` 进行 AES-GCM 加密，密文与哈希单独保存于 `subscription_link_secrets`，不向列表 API 返回。解密载荷绑定订阅 ID，并核对哈希。管理员点击查看使用受鉴权和 CSRF 保护的 POST，响应不缓存，审计只记录动作及资源 ID，不记录 URL、Token、UUID 或密码。

旧 Token 只有哈希，数学上不能恢复原文。旧 URL 继续有效，不重置；管理员可为同一高级订阅按需建立可查看的加密别名，或直接使用用户的统一链接。以后新建高级订阅会加密保留初次发放的同一 Token。明确重置一个订阅时，同时撤销它的旧哈希与全部别名；同一用户其他独立订阅不受影响。密钥丢失或错误时拒绝查看，不自动旋转链接；已有公开 URL 的哈希鉴权仍可工作。

统一订阅的节点集合由用户权限决定，禁止高级编辑修改其归属或私自添加独立节点范围。删除统一链接资源使该资源 URL 失效，之后可由管理员重新建立；普通查看从不执行重置。订阅 URL 是持有即授权的凭据，客户端和管理员都可复制分享，后台只在明确查看时返回。

# v2.5.6 统一订阅生命周期

统一订阅是订阅用户拥有的稳定交付入口，不能在订阅管理中作为独立资源删除或改归属。用户停用/配额决定订阅交付，换地址使用明确确认后的重置；普通查看保留同一 URL。独立高级订阅仍支持删除，其范围和 Token 不与统一订阅混淆。

界面移除统一订阅的删除按钮，保留查看、预览、需确认的重置。API 事务内拒绝删除统一订阅（409），重置接口要求 confirmed=true。独立订阅删除显式清理节点/组/密钥关联，将访问和管理审计的链接引用置空，保留日志。

SQLite foreign_keys 和 busy_timeout 改为驱动每次建立连接时设置，覆盖连接池在 IO 故障后的重连；基线检查前仅应用连接级参数，不更改旧库数据和 journal。无新迁移。对历史残留统一关联返回明确业务错误，不沿残留引用暴露 sql.ErrNoRows，不丢弃加密证据或擅自重置 URL；完整缺失时仍支持首次按需创建。

SG-GCP 修复按一致性备份、精确用户/统一映射/加密材料比对，恢复缺失订阅主体，保留原地址。禁止恢复已清理的三个独立订阅、节点授权、核心账户或计费数据。恢复前后核对全部外键和用户授权。若证据不匹配，拒绝用旧备份覆盖新令牌。

测试覆盖连接池重连后外键约束、统一订阅删除拒绝和 Token 稳定、明确重置、历史悬空关联、正常缺失创建、独立删除日志保留，以及浏览器取消重置/页面按钮。
